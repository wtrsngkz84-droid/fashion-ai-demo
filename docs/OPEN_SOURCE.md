## YOLO 待验证

YOLO 是模型家族名称，不能据此确定全部实现和权重的许可。可选适配器使用 `ultralytics` 导入，但基础依赖不安装它，仓库不包含权重，也不自动下载。必须先选定版本、可信权重来源、哈希和训练数据授权，再审查项目的预期分发方式。

[Ultralytics 官方许可页](https://www.ultralytics.com/license)列出 AGPL-3.0 与 Enterprise 路径；不能把导出 ONNX 或隔离推理服务视为自动免除义务。实际适用范围应按选定代码、权重及部署方式核实。本阶段没有宣称通过商业许可审查。

配置本地权重路径 `YOLO_WEIGHTS` 和 `YOLO_LICENSE_APPROVED=true` 后才尝试加载；该布尔值仅记录人工审核决定，并非程序能够判断许可。适配器要求包含 top/bottom/shoes/dress/outerwear 类别，通用 COCO 检测器不能直接充当衣物分类器。真实精度、类别映射、阈值、CPU/GPU内存、延迟、数据偏差及移动端照片方向都未验证。只加载可信权重，避免不可信序列化文件。

OpenCV/Pillow/其他包仍需在正式发行前生成依赖清单、核对许可证并进行依赖漏洞审计；本次 requirements-lock 是验证环境快照，不代表已完成供应链审计。
