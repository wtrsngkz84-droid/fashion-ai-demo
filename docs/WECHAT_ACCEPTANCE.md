## 可重复的编译命令

从仓库根目录执行，参数换成实际安装位置：

```powershell
node scripts/compile-wechat.cjs 'C:\Program Files (x86)\Tencent\微信web开发者工具'
```

也可设置 WECHAT_DEVTOOLS_PATH。脚本检查退出状态与非空编译产物，临时输出会清理；不会写项目源码，不调用上传/预览接口，不需要服务端口。

## 继续模拟器验收

1. 用户在开发者工具“设置 → 安全设置”开启服务端口；如果新版本另要求CLI访问令牌，在本机配置，不在聊天中发送令牌。
2. 导入本仓库的 miniprogram 目录（不要新建模板覆盖它），先使用游客模式。
3. 启动本地 FastAPI，确认 /healthz 正常。仅本地联调按工具要求配置本地网络访问；不能把跳过域名校验用于发布。
4. 验收首页、衣橱、历史、社区、我的的导航、高度、安全区与深色模式；为每页保存实际模拟器截图。
5. 手动添加上装、下装、鞋子 → 首页发送 → 保存 → 历史查看 → 提交反馈；再检查待洗衣物不参与推荐、删除后过期方案无法保存、接口断线错误与重试。
6. 验收图片选择、上传、坏图与超限提示，并检查未配置YOLO时仍要求手动确认。游客模式限制需逐项记录，不能推断真机可用。
